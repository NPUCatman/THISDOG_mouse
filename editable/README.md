# 正常选择 · 矢量重绘备选

`normal_redrawn.svg` 是依据 `../assets/normal.png` 手工重绘的纯矢量图，229 × 229，箭头、身体、双眼、反光、腮红和嘴巴分别分组。无嵌入位图或外部资源；可在 Illustrator、Inkscape 等矢量编辑器中继续修改。

`正常选择_矢量重绘.cur` 是可直接使用的重绘版，内含 32 / 48 / 64 / 96 / 128 像素，分别设置点击热点，并通过 Windows 加载验证。可在 ArtCursors / RealWorld Cursor Editor 中打开编辑；也可在 Windows 鼠标属性的“正常选择”角色中选择它。

重绘版轮廓更平滑，但眼睛、脚趾和笔画与原图有细微差异，因此主主题仍采用原图提取版。`normal_comparison.png` 左侧是原图提取，右侧是矢量重绘。

`normal_redrawn.png` 是透明预览。`../tools/redraw_normal.py` 保存完整路径与再导出代码，PNG 导出使用当前机器已存在的 Node.js / sharp，不自动安装软件。
